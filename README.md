# Event Tracker

Aplikacja webowa stworzona w ramach projektu akademickiego, służąca do zarządzania wydarzeniami oraz analizy danych.

## Funkcjonalności
- Dodawanie nowych wydarzeń (nazwa, data, lokalizacja, kategoria).
- Wyświetlanie i usuwanie wydarzeń.
- Analiza statystyk wydarzeń według dat, lokalizacji i kategorii.
- Przechowywanie danych w Google Cloud BigQuery.

## Technologie
- **Backend:** Node.js, Express.js
- **Baza danych:** Google Cloud BigQuery
- **API:** REST API

## O projekcie
Projekt edukacyjny zrealizowany podczas studiów, którego celem było zdobycie praktycznego doświadczenia w tworzeniu aplikacji webowych, projektowaniu API oraz integracji z usługami chmurowymi.
